OpenPension

Exploring decentralized pension design through a test-token prototype, with personal accumulation accounts and a longevity-sharing pool. The focus is on explicit rules, reproducible validation, and consistent implementations.

The idea

OpenPension explores how pension rules can be made explicit and independently verifiable. The prototype connects a personal accumulation phase with a later longevity-sharing pool, using test assets to study the behavior of the rules.

What I am working to make explicit

  • How contributions, account balances, and the transition between phases are calculated.
  • How distributions from the longevity-sharing pool follow the stated rules.
  • How independent Python, Solidity, and TypeScript implementations can be checked against the same specification.

The current demo

The linked site is a private test client using test assets. Access requires authorization, and its connected test backend may need to be started separately. This is a prototype for studying and validating the design, not a live pension service.

The next question

Can independent implementations apply the same rules to the same inputs and produce exactly the same results?
